# 供应商决策实验室

在线演示：https://jinyh.github.io/supplier-learning-lab/

当前版本v0.3.0，配套EMBA课程PPT v0.7.2。六步路径覆盖初审、错误代价、能力取舍、证据审查、行动与责任及投入复审；支持条件变化、收益推演与资源优先级讨论。

本仓库只保存公开网页成品，用于AI数据治理教学。全部订单、条款与评估数字为课程合成，证据场景采用预设教学回答。无账号、上传、真实业务系统或API调用。

下载docs/index.html后可离线打开。Three.js许可已包含在HTML中。

GitHub Pages从main分支的/docs目录发布。
