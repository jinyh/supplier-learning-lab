# 供应商决策实验室

EMBA2610《AI时代的数据治理》的课堂合成决策练习，v0.6.1配套PPT v0.11.0。

[在线入口](https://jinyh.github.io/supplier-learning-lab/) · [离线单文件](docs/index.html)

## 六步路径

| 环节 | 学员任务 | 课件 |
|---|---|---|
| 提案初审 | 分别判断A/B，保留最初立场 | P7–P8 |
| 错误代价 | 比较四格结果、两类代价和处置量 | P23–P26 |
| 能力取舍 | 比较少漏报、新增处置、能力缺口和未计成本 | P27–P28 |
| 证据审查 | 先判断，逐份核对依据，再修订结论 | P35–P42 |
| 行动与责任 | 比较合同与生产要求，处理资格、超时和撤权变式 | P55、P72、P73、P76 |
| 投入复审 | 分阶段披露证据、推演收益，记录范围、验收与资源优先级 | P88、P91–P94、P97 |

完整用法45分钟，其中24分钟讲师推演、21分钟既有互动，逐页分配见本地教师讲授说明；全部包含在375分钟内。网页保留选择供前后对照，不给管理决定打标准答案分。

## 内容口径

固定评估样本1,000笔（延迟100、正常900），与提案每日在途规模分开。处理量＝命中＋误报；错误代价＝漏报×单位损失＋误报×复核成本。处理件数不等于总工时，两类错误代价不等于项目ROI。

基准→敏感：少漏5件、多处理75件；在200件能力下缺70件；原成本假设下节省21.5万元。扩容分析只再计尚未包含的增量成本，误报复核不重复扣除。

补充协议v2于9月10日生效，替代本订单v1的交付条款，要求O-0915-K于9月15日齐套可用；9月14日可见物流预计余量17日到达。规则与运输事实分开，系统查询或建议不包含改单、改合同或付款权限。

P55明确另设O-0917-B（合同17日交齐，生产15日需齐套）；P76三个条件变化分别讨论，不混入原订单。P91另设85条预警、60条采纳、35条改善报告的运行记录，仍需对照验证；P94另设年度150万元成本、60万元兑现节省，新增贡献90万元时净额为零。

P88新证据需主动揭示，P97才打开复审；A的82%覆盖、B的11%引用缺口和97%权限测试通过率，任务与分母不同，不直接比较。P28的200件练习约束与P103的250件验收门槛分开。

## 使用与维护

顶部六步导航、键盘左右键、投影字号、全屏与复位可用。取消自动翻页，讲师手动推进。三维订单保留旋转、俯视与分组标签，默认二维表承担准确比较；三维不可用时其分组视图自动回退。

全部数据、回答和权限为课堂合成模拟。没有外部API、真实AI或采购系统调用。课堂选择只保留在当前页面内存；刷新或重新开始清除，不上传、不持久保存。HTML已内嵌引擎、样式和数据，可离线打开。

源码：src/model.mjs保存数据、公式及证据逻辑，src/app.js管理课堂交互，src/scene.js管理三维，src/style.css和src/index.html管理界面。使用锁文件安装依赖，运行npm test及npm run build生成docs/index.html。Three.js 0.180.0和esbuild 0.25.10均锁定；第三方许可随内嵌构建保留。

## 发布与验证

GitHub Pages固定使用main分支的/docs。公开仓库仅含README.md、docs/.nojekyll、docs/index.html，源工程与教师资料保留本地。线上与离线使用同一构建产物，校验值、发布记录与详细测试报告由课程教师在本地保存。

21组算法与模型检查与浏览器关键交互检查覆盖数字、边界、证据撤回、初审到复审记录；检查小屏投影及手机布局。实际教室后排可读性与课堂计时仍需排练。

交互组织参考[Ferrari Learning Lab](https://jinyh.github.io/ferrari-learning-lab/)，重新实现课程内容与界面，没有复用车辆模型、商标或网站源码。

## 技术机制

第三步联动阈值、代价与能力；第四步按权限、版本、重排和引用比较合成检索回放；第五步展开状态、回执与恢复路径。src/mechanisms.mjs保存机制逻辑，src/mechanism-view.js显示过程。

## 学习机制（v0.6.1）

打开页首“学习机制”，在独立实验中比较两种采样策略或两套奖励。进入和关闭不改变六步路径中的初审、复审与授权记录。学习状态只存当前页面内存，刷新清空。

- [主动学习](https://jinyh.github.io/supplier-learning-lab/#learning-active)：真实二维逻辑回归，8条初始标签、120条候选、200条独立测试；每轮4条，6轮，比较随机与不确定性采样。
- [强化学习](https://jinyh.github.io/supplier-learning-lab/#learning-reinforcement)：真实表格Q-learning，多步合成订单环境，两套奖励独立训练；固定种子、独立评测、授权硬限制。训练50轮、到500轮、单步、暂停与重置。

真实算法、合成环境、简化模型，不训练大语言模型，不复现Snorkel研究。错误曲线允许波动；奖励和实际经营结果分开观察。网页与离线HTML由同一构建生成，不需要服务器或外部模型。

配套PPT：P17（2分钟操作）、P84（3分钟）、P86（1分钟）；网页45分钟已包含在375分钟课程内。知识卡C13、C15可从实验内打开。
