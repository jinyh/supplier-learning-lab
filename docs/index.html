课堂使用说明

沿六步路径，在相应PPT页面切入。由讲师手动推进，先讨论再揭示分析；第六步在P88揭示证据，P97才打开复审记录。第五步分别提供P55合同变式、P66原订单交接和P76授权变化。

  • 分别审议A、B，没有预设的投资“标准答案”。条件、依据和责任人是讨论重点。
  • 全部业务数字、材料和回答为课程合成。学习机制在浏览器内运行简化算法；页面不调用外部模型、业务系统或外部API；选择仅保留在本页内存，刷新或重新开始会清除。
  • 1,000笔是固定评估样本，实际延迟100、正常900；与提案每日在途规模分开。
  • 错误代价只计漏报损失及误报复核，不是项目总成本或ROI；处理件数不等于总工时。调整参数只改变假设。
  • 第三、四、五步可展开技术机制，依次检查阈值与校准、检索组件、执行状态。分数与回答均为合成执行回放。
  • 三维仅用于观察订单分组；主界面的二维表保留准确分母。键盘左右键换步骤，表单输入时不触发换页。
  • “投影字号”放大正文；“全屏”扩大教学画面。网页支持手机纵向滚动和离线单文件使用。

技术机制视图对应PPT v0.11.0 P28–P29、P35–P39、P72/P73。交互路径参考 Ferrari Learning Lab；三维使用Three.js。
